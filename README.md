# Azure Kubernetes Project

The aim of this project is to build a production grade Kubernetes Cluster within Microsoft Azure Cloud platform. The goal is to further my knowledge in Kubernetes within a Cloud environment and continue my journey on becoming a DevOps Engineer. 

# Goal:
The final product will be a fully operational n8n solution hosted within AKS. Data will be stored on self-hosted PostgreSQL databases which will be backed up periodically. The AKS cluster is setup via Terraform and the cluster will be managed through GitOps.  

# Workflow:

The project is divided into phases, each phase an incremental development. Each phase will be described below in a short summary.

**Phase 1** – Learn Terraform and setup basic infrastructure in Azure such as resource group, virtual network, subnet, network interface, network security group, and an initial virtual machine.

**Phase 2** – Learn about Terraform modules and how to build and implement Terraform modules. 

**Phase 3** – Azure Kubernetes Service and Terraform. Implement first AKS infrastructure through Terraform.  

**Phase 4** – Security, integrating Azure Key vault for secrets management. 

# Project Background:

This project is part of Mischa van den Burg’ KubeCraft course. While my project follows the same layout as the course, I make my own customizations and changes, and these are reflected in my work.
